# Raw data

Download the four CWRU bearing recordings into this folder (they are not
committed to git):

```
curl -O https://engineering.case.edu/sites/default/files/97.mat    # healthy baseline
curl -O https://engineering.case.edu/sites/default/files/105.mat   # inner-race fault
curl -O https://engineering.case.edu/sites/default/files/118.mat   # ball fault
curl -O https://engineering.case.edu/sites/default/files/130.mat   # outer-race fault
```

Source: Case Western Reserve University Bearing Data Center.
